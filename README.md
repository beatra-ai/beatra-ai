# Beatra AI

**Generate images, video, music, and speech from the agent you already use.**

在 Claude Code、Codex、OpenClaw 里直接出图、出视频、做音乐、配音。

---

Beatra ships **Agent Skills**: packages your coding agent loads to plan, direct, and review creative work, then render it on [Beatra](https://beatra.ai). Every skill is free to install. Rendering uses credits on your Beatra account, and paid steps run only when you approve them.

## Quick start

```bash
# Browse the full catalog (200+ skills)
npx skills add beatra-ai/beatra-skills --list

# Or install the all-in-one skill: images, video, music, and voice
npx skills add beatra-ai/ai-media-generator-skill
```

Works with **Claude Code**, **Codex**, **OpenClaw**, and any agent that reads `SKILL.md`.
